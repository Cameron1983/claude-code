# 风格候选 · 天台坠落（1.5–1.7）

共同基底：2.39:1，35mm胶片质感，轻颗粒，浅景深，稳定克制的运镜，无手持晃动。

## A「克制的诗意」（推荐）
- 光：以月光为主光，冷银蓝；天台只有远处校园路灯的一点暖黄作辅光。
- 影调：低对比、暗部有层次不死黑，肤色偏暖保住人的温度。
- 运镜：缓推、缓拉、长静止；坠落段几乎不动机位，让时间"停住"。
- 坠落段变体：天空占画面三分之二以上，流星雨细而亮，那颗特别的流星带金青色流光，倒映在林嘉眼中。
- 声音：天台段写实环境声；坠落后抽空环境声，只留呼吸与低频长音。
- 禁忌：霓虹、高饱和、夸张鱼眼、快速摇镜、漫画式特效光。

## B「冷暖对撞的青春悬疑」
- 光：天台暖黄灯 + 冷蓝月光强对比，轮廓光明显，略带泛光。
- 影调：中高对比，色彩更鲜明，更接近都市青春电影。
- 运镜：轻微手持呼吸感，坠落时过渡到平稳。
- 风险：与"诗意宇宙"参考有距离，坠落段的宏大感较弱。

## C「冷峻的宇宙视角」
- 光：几乎纯自然月光与星光，低饱和，银灰青为主。
- 影调：深黑背景，星空极致清晰，人物在天空下显得渺小。
- 运镜：全程广角、缓慢，人物多为中远景。
- 风险：人物情绪与对话戏的亲近感不足，天台醉酒对话会偏冷。

## 建议的变体设计
- 变体1「天台·写实」：A 的月光 + 暖黄辅光，人物近景为主。
- 变体2「坠落·诗意」：继承 A，色温再冷一档，画面拉开，星空占主体，慢到近乎静止。
- 两个变体之间用"被甩出天台"的瞬间过渡，作为全片的视觉转折。
