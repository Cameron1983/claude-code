# 镜头语言与摄影机知识库 (Shot Grammar)

拆分镜头、设计运镜时使用本文件作为术语与选用依据。中文术语 + 英文提示词关键词并列，便于直接用于视频生成提示词。

## 一、景别 (Shot Size)

按镜头中主体占画面比例，由远到近：

| 中文 | 英文 / 提示词关键词 | 作用 |
|---|---|---|
| 大远景 / 极远景 | extreme wide shot, establishing shot | 交代环境规模、地理位置，开场或转场常用 |
| 远景 | wide shot (WS), long shot | 展示人物与环境关系，人物占比小 |
| 全景 | full shot (FS) | 完整展示人物全身及动作，适合展示肢体表演 |
| 中景 | medium shot (MS)，约膝盖/腰部以上 | 对话、日常互动的标准景别 |
| 中近景 | medium close-up (MCU)，约胸部以上 | 强调表情同时保留少量肢体语言 |
| 近景 | close-up (CU)，头肩部 | 聚焦情绪、细微表情变化 |
| 特写 | tight close-up | 单一面部特征、关键道具、局部细节 |
| 大特写 | extreme close-up (ECU) | 眼睛、指尖、水滴等，强烈情绪/悬念/细节强调 |

**使用原则**：一场戏一般由"建立镜头（大远景/远景）→ 中景交代关系与对话 → 近景/特写强化情绪或关键信息"构成节奏起伏，避免全片同景别导致乏味。

## 二、机位角度 (Camera Angle)

| 中文 | 英文关键词 | 心理/叙事效果 |
|---|---|---|
| 平视 | eye-level shot | 中立、代入感强，最常用 |
| 俯拍 | high angle shot | 使主体显得弱小、被压制、脆弱 |
| 仰拍 | low angle shot | 使主体显得强大、威严、崇高 |
| 鸟瞰 | bird's-eye view, top-down shot | 展示全局格局、命运感、地图式信息 |
| 虫视 / 极低机位 | worm's-eye view | 强烈压迫感、纪念碑感 |
| 荷兰角 / 斜角 | dutch angle, canted angle | 制造不安、失衡、混乱、精神失常暗示 |
| 过肩镜头 | over-the-shoulder shot (OTS) | 对话场景，强调视角归属与人物关系 |
| 主观镜头 | point-of-view shot (POV) | 让观众代入角色视角，增强沉浸感 |

## 三、运镜方式 (Camera Movement)

| 中文 | 英文关键词 | 效果与用法 |
|---|---|---|
| 固定镜头 | static shot, locked-off shot | 稳定、克制，让画面内容/表演自身说话 |
| 推镜 | dolly in / push in | 镜头向主体推进，制造聚焦、紧张、揭示感 |
| 拉镜 | dolly out / pull out | 镜头远离主体，制造揭示环境、孤立、疏离感 |
| 摇镜 | pan (左右) / tilt (上下) | 机位不动，镜头转动，用于扫视环境或引导视线转移 |
| 移镜 / 轨道镜头 | tracking shot, trucking shot | 摄影机随主体平移，保持相对位置，增强跟随感 |
| 跟拍 | follow shot | 摄影机跟随主体运动方向移动，常配合手持增强沉浸/动感 |
| 升降镜头 | crane shot / boom shot | 垂直方向大幅度移动，展现空间规模或视角权力变化 |
| 手持 | handheld, shaky cam | 真实感、纪实感、紧张不安 |
| 稳定器/斯坦尼康 | steadicam shot | 流畅的跟随长镜头，兼具移动感与稳定感 |
| 无人机航拍 | aerial shot, drone shot | 大场面、地理关系、开场/结尾的宏观镜头 |
| 变焦 | zoom in / zoom out | 光学放大/缩小而非物理移动，比推拉更"平面"、更具压迫感 |
| 希区柯克变焦 | dolly zoom (vertigo effect) | 推镜同时反向变焦，制造眩晕、认知失调的强烈心理效果 |
| 环绕镜头 | orbit shot, arc shot | 围绕主体旋转，展示立体感或强调关键时刻 |
| 甩镜 | whip pan | 快速摇镜制造模糊过渡，常用作有节奏感的转场 |
| 长镜头 | long take, one-shot | 不切镜连续记录，强调真实时间流逝与场面调度 |

## 四、镜头焦段 / 光学特性 (Lens)

| 焦段 | 关键词 | 视觉特征 |
|---|---|---|
| 超广角 | ultra-wide lens (14-24mm) | 视野广、边缘畸变、夸张透视，适合空间感/冲击力 |
| 广角 | wide-angle lens (24-35mm) | 环境与人物兼顾，纪实感 |
| 标准 | standard lens (35-50mm) | 接近人眼视角，自然真实 |
| 中长焦 | portrait lens (85mm) | 轻微压缩透视，人像特写常用，背景虚化自然 |
| 长焦 | telephoto lens (135mm+) | 强压缩感，背景虚化强烈，偷窥感/距离感 |
| 微距 | macro lens | 极近距离细节，用于道具、质感特写 |
| 浅景深 | shallow depth of field, bokeh | 主体清晰背景虚化，突出主体、电影感 |
| 大景深 | deep focus | 前后景皆清晰，适合展示场面调度/多层信息 |

## 五、构图法则 (Composition)

- **三分法 (rule of thirds)**：主体置于九宫格交点，画面更平衡自然。
- **对称构图 (symmetrical composition)**：庄重、仪式感、强迫症式美感（韦斯·安德森常用）。
- **引导线 (leading lines)**：利用道路、栏杆等线条引导视线至主体。
- **框架式构图 (frame within a frame)**：用门框、窗户等制造画中画，强调窥视或聚焦。
- **前景遮挡 (foreground framing)**：前景物体部分遮挡主体，增加层次与纵深。
- **负空间 (negative space)**：大面积留白衬托主体，营造孤独/渺小/极简感。
- **对角线构图 (diagonal composition)**：制造动感与张力。

## 六、剪辑节奏与转场

- **切 (cut)**：默认转场，干净利落。
- **匹配剪辑 (match cut)**：前后镜头动作/形状呼应，制造联想（如经典的骨头→飞船）。
- **跳切 (jump cut)**：同一主体不连续的剪辑，制造时间跳跃感或不安感。
- **叠化 (dissolve/cross-dissolve)**：柔和过渡，常表示时间流逝或梦境/回忆。
- **淡入淡出 (fade in/out)**：段落起止，强调完整段落感。
- **轴线规则 (180-degree rule)**：正反打对话镜头需保持摄影机在假想轴线同侧，避免观众方向感混乱。
- **节奏 (pacing)**：动作/紧张场景用短镜头快切（1–3 秒/镜）制造张力；抒情/氛围场景用长镜头慢切（5–10 秒+）营造沉浸。
