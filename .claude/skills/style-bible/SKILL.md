# 风格圣经

目标：把导演模糊的"感觉"变成可被提示词直接引用的、固定的语言。电影感主要来自这份文件的一致性。

## 步骤
1. 读剧本与 `status.md`，提炼：题材、时代、情绪基调、一句话主题。
2. 向导演问（一次最多3问，附推荐）：参考影片/摄影师、画幅与成片时长、整体明暗与色彩倾向。
3. 给出**2–3个风格方案**，每个用一段话 + 关键词描述，让导演选或混合。
4. 确认后写入 `style_bible.md`，结构见 `references/template.md`。
5. 生成一段**风格锁定句**（中英各一，40–80字），能原样粘贴进每条提示词开头。

## 要点
- 具体到可执行：色温、对比度、颗粒、镜头焦段感、景深、运镜气质，而不是"高级""唯美"。
- 写**禁忌清单**（如：不要霓虹、不要手持晃动、不要现代元素），后续用作负面提示。
- 不同场景可有「变体」（如夜戏/回忆），但必须声明继承关系。
- 导演确认后才算冻结；冻结后的改动要记入 `status.md` 并触发返工评估。
