# 连续性台账

文件：`continuity_ledger.md`。它是所有镜头共享的"事实表"，提示词从这里取状态，审核拿它对照。

## 结构
```
## 角色
### <角色名>
- 固定描述词（外貌/发型/年龄感，每次提示词原样使用）：
- 服装版本：V1(场景范围) …
- 状态时间线：
  | 镜头 | 服装 | 伤/污/湿 | 手持物 | 情绪 |
## 道具
### <道具名>
- 固定描述词：
- 状态时间线：镜头 | 位置 | 状态（完好/破损/开合）
## 场景
### <场景名>
- 固定描述词、时间、天气、光源
- 轴线：A在左B在右 …
## 开放问题
```

## 用法
- **写入**：每当镜头表新增/修改镜头，补全对应行；设定变更时标出受影响镜头。
- **读取**：写提示词前取目标镜头的前一镜状态，保证延续。
- **检查**：新镜头加入时自动核对：道具是否凭空出现/消失、服装是否突变、视线与轴线是否翻转、光线时间是否跳变。发现冲突列出来，不要默默改。
- 表格保持紧凑，只记会变的东西。
