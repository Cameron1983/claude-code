# 设定设计（人物 / 场景 / 道具）

## 铁律
**设定图未经导演确认，不进入视频生成。** 所有视频提示词引用的参考图，必须在 `assets/asset_registry.md` 里状态为 `confirmed`。

## 步骤
1. 读 `style_bible.md`、`characters/ scenes/ props/` 设定文档、`continuity_ledger.md`。
2. 列出**素材清单**：每个角色（常规版 + 特殊版，如露脸/不露脸）、每个主场景（含空镜）、关键道具。每项写明被哪些生成单元引用。
3. 为每项写**图像提示词**，写入 `assets/asset_prompts.md`：
   - 中英各一版（英文用于出图，中文便于导演审阅）。
   - 开头原样带风格锁定句里与画面相关的部分；角色用 `characters/` 里的固定描述词。
   - 注明：输出规格（4K、宽高比）、参考输入（如"用 C2a 作图生图参考"）、需要文字的地方（逐字写明）、负面提示。
   - 角色设定图用中性灰底、多视图，场景图用电影宽幅。
4. 建立 `assets/asset_registry.md`：编号、名称、用途、文件名、状态（pending / generated / confirmed / rejected）、被哪些单元引用、备注。
5. 导演把出好的图交回来后：逐张查看，对照设定与风格圣经，指出不一致（五官、服装、光向、比例、文字错误），再让导演确认或重生成。
6. 全部必要素材 `confirmed` 后，通知 director-control 进入镜头提示词阶段。

## 注意
- 出图模型的最大分辨率与宽高比支持以导演实际使用的工具为准；不支持的比例先出相近比例再裁切。
- AI 生成文字不稳（尤其中文）：需要文字的图一次出多张候选，挑字形正确的；仍不行则留空，后期叠字。
- 同一角色的多张图，后出的图要以先出的图作参考输入，保证一致。
